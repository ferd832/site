### Шаг 2: Проверить таблицы

После выполнения миграций у вас должны появиться таблицы:
- `user_profiles` - профили пользователей
- `artists` - артисты
- `releases` - релизы/отгрузки
- `lyrics` - тексты песен

### Шаг 3: Создать первого пользователя

1. Перейдите в **Authentication** → **Users**

2. Нажмите **Add user** → **Create new user**

3. Введите email и пароль

4. После создания пользователя автоматически создастся профиль в таблице `user_profiles`

5. Чтобы сделать пользователя админом, выполните SQL:
```sql
UPDATE user_profiles 
SET role = 'admin' 
WHERE id = 'YOUR_USER_ID';
```

### Шаг 4: Настроить Storage (опционально)

Если хотите загружать файлы (аудио, обложки):

1. Перейдите в **Storage**

2. Создайте bucket с именем `uploads`

3. Сделайте его public или настройте политики доступа
